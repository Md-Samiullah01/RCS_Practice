## Overview

This repository contains two handy reference resources for anyone getting started with Git and Visual Studio Code:

| File                       | Purpose                                                                                                                                                                                                                        |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **`git-cheatsheet.md`**    | A concise, beginner‑friendly cheat sheet that explains the most common Git commands, their typical usage, and quick‑reference tables.                                                                                          |
| **`vscode-extensions.md`** | A curated list of beginner‑friendly VS Code extensions (including Code Runner, Error Lens, Git Graph, VS Code Icons, etc.) together with short descriptions of why they’re useful, plus a table of essential VS Code commands. |

These files are meant to be printed, bookmarked, or opened directly in the editor for fast lookup while you code.

## How to Use

1. **Open the appropriate file** in VS Code (or any markdown viewer).
2. **Search (`Ctrl + F`)** for the command or extension you need.
3. Follow the one‑line examples or explanations to apply the command/extension in your own project.

Both files are written in plain Markdown, so you can easily add your own notes or additional entries.

## Contributing

Feel free to submit pull requests to improve or expand the lists:

- Add missing Git commands or clarify existing explanations.
- Suggest new VS Code extensions that are helpful for beginners.
- Propose extra VS Code shortcuts or workflow tips.

When contributing, please keep the format consistent with the existing tables and keep explanations concise.
